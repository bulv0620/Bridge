# Bridge 产品定义

## 产品定位

Bridge 是一款 Electron 桌面应用，用于在用户明确选择的位置之间比较和同步文件，以及在
同一局域网内发现其他 Bridge 设备、传输单个文件和共享剪贴板内容。

当前支持 Windows、macOS 和 Linux。应用采用单实例运行，关闭主窗口时默认隐藏到系统托盘，
通过托盘退出才会结束进程。

## 当前产品能力

### 文件同步

- 最多同时保存和恢复 3 个同步会话。
- 端点类型包括本地目录、FTP/FTPS 和 S3/S3 兼容服务。
- 支持镜像、增量和双向三种策略。
- 比较结果以树形差异列表呈现，用户可以逐文件改变处理方向或选择忽略。
- 支持按文件夹名称配置忽略项。
- 能够停止正在进行的比较或同步；停止是协作式的，在当前异步操作返回后生效。
- 会话名称和表单配置持久化，比较结果和同步进度不持久化。

同步的精确判定和覆盖/删除语义以
[`../behavior/sync-semantics.md`](../behavior/sync-semantics.md) 为准。

### 局域网共享

- 用户启用局域网发现后，应用通过 IPv4 UDP 广播声明设备和服务能力。
- 可向支持文件接收的在线设备发送一个用户选择的文件。
- 接收方必须启用文件接收能力，并在原生确认对话框中同意后才开始传输。
- 可以共享文本、HTML、PNG 和 JPEG 等剪贴板内容；大内容通过临时文件传输。
- 发送和接收任务在当前运行周期内展示，不作为长期历史持久化。

协议和信任边界以
[`../behavior/lan-sharing.md`](../behavior/lan-sharing.md) 为准。

### 设置、诊断与更新

- 支持浅色、深色和跟随系统主题。
- 支持简体中文和英文。
- 日志级别支持 `info` 与 `debug`。
- 用户可以查看日志目录、清理日志、导出诊断压缩包。
- 打包环境中可以检查、下载并安装 GitHub Release 更新；开发环境跳过更新检查。

## 当前非能力

除非后续 Spec 明确增加，不能假定 Bridge 已具备以下能力：

- 云端账号、中心服务器或跨互联网设备发现。
- 设备身份认证、端到端加密或可信设备配对。
- 文件版本历史、回收站、事务性同步或失败后的自动回滚。
- 基于文件内容哈希的相等判断。
- 持久化的传输历史或同步执行历史。
- 后台定时同步、实时目录监听或多人协作权限模型。
- 自动化测试套件和普通分支/拉取请求 CI。

## 核心产品原则

1. **用户控制数据变更**：同步、文件接收和诊断导出必须由用户明确触发。
2. **数据安全优先**：删除、覆盖、冲突和路径处理的变化必须通过明确 Spec 批准。
3. **端点对等表达**：UI 中的左侧是 source，右侧是 destination；方向描述不得含糊。
4. **跨平台可预期**：路径、标题栏、托盘和原生对话框必须考虑三个平台差异。
5. **隐私最小化**：日志与诊断不得包含密码、密钥、令牌或完整剪贴板内容。

## 产品术语

| 术语                  | 含义                                             |
| --------------------- | ------------------------------------------------ |
| source / 源端         | 同步表单左侧端点                                 |
| destination / 目标端  | 同步表单右侧端点                                 |
| endpoint / 端点       | 本地、FTP 或 S3 中的一个已配置位置               |
| session / 同步会话    | 一组端点、策略、忽略配置和运行时状态             |
| difference / 差异项   | 比较后需要展示或处理的文件/目录                  |
| resolution / 处理方向 | `toLeft`、`toRight`、`ignore` 或目录的空值       |
| capability / 服务能力 | 局域网设备声明的 `file-push`、`clipboard` 等能力 |
| RemoteRef             | 主进程和渲染进程之间同步轻量状态的项目内机制     |
