# 端点卡片与存储容量展示调整

## 元信息

- 状态：Verified
- 级别：M
- 类型：Bug / Interaction / Platform
- 创建日期：2026-07-24
- 负责人：Codex
- 关联 issue：无
- 关联 ADR：无

## 背景

文件同步页面使用端点卡片展示 source 和 destination。当前卡片底部始终保留容量区域，但只有
本地存储实现了容量查询，FTP 和 S3 的容量查询固定返回空值，因此远端存储会长期显示没有有效
内容的区域。

Windows 本地容量查询当前通过 `wmic logicaldisk` 执行。代码已经明确记录该命令在部分新版
Windows 中可能不可用；查询异常会被转换为 `undefined`，renderer 因而只显示空容量条，不会
区分“不支持”和“查询失败”。这是 Windows 选择本地目录后不显示容量信息的已确认代码路径，
是否与报告问题所在设备完全一致仍需 Windows 实机验证。

容量结果当前写入 `StorageEngineConfig.storageCapacity`。同步会话会持久化整个表单，因此这个
运行时结果可能被一并保存；配置写入和容量查询之间也没有明确的串行等待或过期请求保护。

未选择端点时，点击卡片会打开覆盖整张卡片的存储类型选择层。选择层顶部的 Back 操作占据一行，
但该层使用向上进入、向下退出的动效，Back 的层级语义与实际关闭行为不一致。

## 目标

- 修复 Windows 本地存储容量查询在可访问目录上的兼容性问题。
- 仅在容量信息有意义时提供紧凑的容量入口，不再使用常驻卡片 footer。
- 重新组织端点卡片和存储类型选择层，保持明确的信息层级和关闭语义。
- 保证所有存储类型和所有界面状态下的端点卡片高度一致。
- 将容量作为运行时状态管理，避免持久化旧容量和异步结果错配。

## 非目标

- 不为 FTP、FTPS、S3 或 S3 兼容服务估算、遍历或伪造容量。
- 不改变端点连接表单、连接校验或目录浏览行为。
- 不改变同步比较、方向、删除、覆盖、停止和三种同步策略语义。
- 不新增存储配额告警、系统通知或自动清理能力。
- 不改变 source、destination 和同步策略控件的页面层级。

## 当前行为

- 端点卡片无论是否选择端点、是否支持容量，都会渲染容量标题和进度条区域。
- Local 查询成功时显示“已用 / 总量”和线性进度条。
- FTP 和 S3 返回 `undefined`，卡片仍显示空容量区域。
- Windows Local 使用 `wmic`；macOS 和 Linux 使用 `df -k`。
- 容量查询失败不会向 UI 提供明确的失败状态。
- 容量结果存放在端点配置对象中，可能进入持久化会话。
- 未选择端点时，卡片内选择层包含单独的 Back 行。

## 目标行为

- REQ-01：所有 source 和 destination 端点卡片 MUST 使用同一个固定高度规则。未选择、Local、
  FTP、S3、容量加载、容量成功、容量失败、禁用以及存储类型选择层展开时，卡片外部高度 MUST
  保持一致；容量入口、加载状态、警告状态和 Popover MUST NOT 改变卡片高度。
- REQ-02：卡片 MUST 移除常驻容量 footer。容量入口 MUST 位于卡片右下角的既有内容区域内，
  与右上角的移除操作共同构成右侧操作区，不得新增会改变卡片高度的内容行。
- REQ-03：容量查询成功时，卡片右下角 MUST 显示小型圆环。圆环 MUST 表示
  `used / total` 的已用比例，视觉直径 SHOULD 为 22–24px；其可点击区域 MUST 至少为
  44×44px，且不得遮挡路径、移除按钮或其他交互。
- REQ-04：容量圆环 MUST 使用现有主题语义色。已用比例低于 75% 使用主题色，75%（含）至
  90% 使用警告色，90%（含）以上使用危险色。颜色不得成为唯一信息来源。
- REQ-05：点击容量圆环 MUST 打开锚定在圆环上方的小型 Popover，展示总容量、已用容量、
  可用容量和已用百分比。可用容量按 `max(total - used, 0)` 展示。Popover MUST 浮于布局之上，
  不得推动或缩放卡片。
- REQ-06：点击容量圆环或操作 Popover MUST NOT 触发卡片的端点编辑行为。再次点击圆环、
  点击外部或按 Escape MUST 能关闭 Popover。
- REQ-07：容量入口 MUST 可通过键盘聚焦，并支持 Enter 或 Space 打开。入口 MUST 提供包含
  已用百分比的可访问名称；Popover 的阅读顺序 MUST 与视觉顺序一致，并保持可见焦点样式。
- REQ-08：FTP、FTPS 和 S3 当前 MUST 被标记为不支持容量查询。它们 MUST NOT 发起容量查询，
  MUST NOT 显示容量圆环、加载状态、失败状态或占位区域。
- REQ-09：Local 选择完成或已保存的 Local 会话恢复后 MUST 异步查询容量。查询超过 300ms 时
  SHOULD 在圆环位置显示紧凑加载状态；加载状态不得改变卡片尺寸。
- REQ-10：Local 容量查询失败时 MUST 区别于“不支持”。卡片右下角 MUST 显示弱化的警告入口；
  点击后 MUST 说明容量信息暂不可用并提供重试操作。失败不得阻止端点用于比较或同步。
- REQ-11：Local 容量查询 MUST 使用 Node.js 文件系统容量 API，以所选目录所在文件系统为
  查询目标，不再依赖 `wmic`、`df` 或其他 shell 命令。结果 MUST 使用字节表示，并满足
  `total > 0`、`0 <= used <= total`；无效结果按查询失败处理。
- REQ-12：容量状态 MUST 与持久化的 `StorageEngineConfig` 分离。加载状态、查询结果和错误状态
  MUST 仅存在于当前运行时同步会话，不得写入 `syncSessions`。
- REQ-13：端点配置写入主进程后才能查询对应容量。端点被替换、移除、会话关闭或请求过期后，
  旧查询结果 MUST NOT 写入新端点或已销毁会话。
- REQ-14：存储类型选择层 MUST 移除 Back 行。Local、FTP 和 S3 三个选项 MUST 在卡片主体内
  等宽排列，并提供独立的关闭按钮；该按钮语义 MUST 为“关闭选择”而不是“返回”。
- REQ-15：存储类型选择层 SHOULD 向上进入、向下退出，进入和退出 SHOULD 在 150–250ms 内完成。
  动效 MUST 使用 transform/opacity，且在用户启用 reduced motion 时 MUST 关闭或显著减弱。
- REQ-16：存储类型选项和关闭按钮 MUST 使用语义化交互元素，支持键盘焦点、Enter/Space 选择
  和 Escape 关闭。交互禁用时不得打开选择层、原生目录选择器或连接配置弹窗。
- REQ-17：新增或修改的容量、失败、重试和关闭文案 MUST 同步提供简体中文和英文翻译。
- REQ-18：容量信息是辅助信息。容量查询、重试和 Popover 的任何失败 MUST NOT 改变端点配置，
  MUST NOT 阻塞比较或同步，也 MUST NOT 改变同步数据语义。
- REQ-19：容量圆环的未使用轨道 MUST 在卡片默认背景和 hover 背景上保持清晰可辨，并使用比原
  实现更深的中性灰色；轨道与已用进度仍需通过颜色和形状共同表达。
- REQ-20：容量圆环的 hover 状态 MUST NOT 在 44×44px 点击热区内增加额外的圆形背景。视觉
  圆环保持 22–24px，键盘 focus 状态仍 MUST 保留明确的可见焦点。
- REQ-21：未选择端点时 MUST 使用区别于已选择端点的紧凑空状态，包括克制的图形容器、端点角色
  和一句简短选择提示。空状态 MUST NOT 使用长描述文本，MUST NOT 增加卡片高度，也不得削弱整张
  卡片可点击的交互提示。
- REQ-22：容量圆环及其内部 SVG 在 hover 时 MUST 显示 pointer 光标，明确表达可点击性；不得
  依赖浏览器对子元素的光标继承实现该反馈。
- REQ-23：已选择端点的卡片 MUST 在固定高度内建立清晰的信息层级：图标使用克制的视觉容器，
  存储类型与 source/destination 角色同时可见，路径使用独立的紧凑承载区域。短路径（包括 `/`）
  MUST 保持明确的结构感，长路径 MUST 截断且不得挤压右侧操作区。
- REQ-24：未选择端点的角色和选择提示 MUST 始终占据上下两行，不得因组件默认 display 或可用
  宽度合并到同一行。已选择端点的类型、角色和路径 MUST 共享同一左边界；角色和路径不得各自使用
  互不关联的胶囊容器。关闭按钮与容量入口 MUST 各自使用 44×44px 点击区域；关闭按钮的可见圆形
  MUST 为 30×30px，容量圆环保持 24×24px。两者作为固定高度的右侧操作组整体垂直居中，不得使用
  单独 margin 或 transform 偏移。FTP/S3 等没有容量入口时，关闭按钮 MUST 继续占据与 Local
  相同的右上位置，不得改为单独垂直居中。
- REQ-25：Local、FTP 和 S3 图标 MUST 使用统一的 24×24 画布、简约系统符号风格、单色细描边、
  圆角端点和颜色继承方式；仅可使用少量透明度建立层级，不得使用大面积填充。Local MUST 直观
  表达本地磁盘，FTP MUST 同时表达服务器与双向传输，S3 MUST 表达对象存储；不得使用大段文字、
  与类型无关的上传图形或彼此不一致的复杂填充插画。

## 用户流程与界面状态

### 未选择

卡片显示端点角色、未选择提示和存储图标，不显示容量相关元素。点击卡片打开卡片内的存储类型
选择层。选择层与普通卡片外部尺寸相同。

### 选择存储类型

选择层显示 Local、FTP 和 S3 三个等宽按钮以及关闭按钮，不显示 Back 行。关闭或按 Escape 后
恢复未选择卡片。选择 Local 后打开系统目录选择器；取消系统选择后仍保持未选择。选择 FTP/S3
后沿用现有连接配置流程。

### Local 加载

Local 配置写入主进程后开始查询容量。查询时间不超过 300ms 时可以直接从无入口过渡到容量圆环；
超过 300ms 时在同一右下角操作区域显示加载状态。卡片高度和相邻控件位置不发生变化。

### Local 成功

右下角显示已用比例圆环。点击后显示总容量、已用容量、可用容量和百分比。关闭 Popover 后焦点
返回圆环入口。

### Local 失败与重试

右下角显示弱化警告入口。点击后显示“容量信息暂不可用”和重试操作。重试期间切换为加载状态；
成功后切换为容量圆环，失败则恢复警告入口。比较和同步操作始终不受容量状态影响。

### FTP / S3 不支持

卡片不查询、不展示也不为容量预留独立 footer。卡片高度仍与 Local 卡片完全一致，内容使用同一
基础卡片布局。

### 禁用与中断

比较或同步期间，卡片、移除操作和存储类型选择操作保持禁用。已经打开的容量 Popover MAY 关闭，
但不得通过它改变端点。端点切换、移除或会话销毁时取消当前 UI 状态并忽略随后返回的旧容量结果。

## 数据、接口与迁移

- IPC / RemoteRef：`sync:getCapacity` 的返回值从含糊的 `StorageCapacity | undefined` 调整为可区分
  `ready`、`unsupported` 和 `unavailable` 的结果。`loading` 是 renderer 运行时状态，不通过
  RemoteRef 持久化。具体判别联合类型在实现时放入共享类型层，并保持 renderer 可解析。
- 持久化 schema：`StorageEngineConfig` 不再包含运行时 `storageCapacity`。`syncSessions` 的持久化
  外层结构不变，不增加 schema 字段。
- 已有数据迁移：读取历史会话时 MUST 容忍旧配置中的 `storageCapacity`，但 MUST 忽略该字段；
  下一次保存会话时 MUST 将其移除。无需破坏性迁移或清空用户端点配置。
- 回退/降级：容量查询失败降级为警告入口，端点本身继续可用。FTP/S3 明确降级为不展示容量。
  回退旧版本时，旧版本应能忽略缺失的可选 `storageCapacity`。

## 安全与隐私

- 本次变更不修改同步删除、覆盖、读取或写入语义。
- Local 容量查询只能使用用户已经选择的目录，不新增任意路径读取 IPC。
- 不得把完整本地路径、FTP/S3 凭据或容量查询底层错误详情展示在 Popover、日志或诊断导出中。
- 移除 shell 容量命令后，不再需要把所选路径插入命令字符串，收窄命令执行和路径转义风险。
- FTP/S3 不得为了估算容量而遍历对象、请求非标准配额接口或记录凭据。

## 跨平台影响

- Windows：使用 Node.js 文件系统容量 API 查询所选目录所在卷，覆盖固定盘符、非系统盘和可访问
  路径；必须在 Windows 实机验证报告问题。网络共享路径是否支持由运行时 API 和权限决定，失败时
  按 unavailable 降级。
- macOS：使用相同文件系统容量 API 代替 `df`，必须验证普通本地目录和深色/浅色主题。
- Linux：使用相同文件系统容量 API 代替 `df`，必须验证普通本地目录；不同挂载类型的结果遵循
  Node.js API。
- 三个平台上的卡片 DOM 布局和固定高度规则相同；仅原生目录选择器行为沿用平台差异。

## 实现约束

- 文件系统容量查询保留在主进程的 Local 存储引擎内，renderer 不得直接使用 Node.js 或 Electron
  文件系统能力。
- 必须继续通过现有 preload/IPC 边界访问容量，不新增通用路径或命令执行能力。
- 容量 UI 状态属于 renderer 同步会话运行时状态；端点配置只保存建立存储引擎所需的数据。
- 卡片高度必须由单一共享样式规则控制。圆环、警告入口和加载入口放入卡片内部固定操作区；
  Popover 使用浮层，不参与常规文档流。
- 优先复用 Element Plus 的圆形进度、Popover、按钮、加载和图标能力以及现有主题变量，不引入新
  UI 依赖，不硬编码与现有主题冲突的颜色。
- 不得为了容量展示修改 `StorageEngine` 的同步读写、删除、路径解析或连接生命周期语义。
- 实现完成后同步更新 `docs/behavior/sync-semantics.md` 的容量降级规则，以及
  `docs/architecture/ipc-and-state.md` 的容量 IPC 与运行时状态所有权。

## 验收标准

- AC-01
  - Given source 和 destination 分别处于未选择、Local 成功、Local 加载、Local 失败、FTP、S3、
    禁用和选择层展开状态
  - When 在同一窗口尺寸和缩放比例下测量每张 `.endpoint-card` 的外部矩形
  - Then 所有卡片高度来自同一固定规则，任意两种状态的高度差不超过 1px，且圆环或 Popover
    打开前后高度差不超过 1px

- AC-02
  - Given Windows 上选择一个有访问权限的本地目录
  - When 容量查询完成
  - Then 不调用 `wmic`，右下角显示容量圆环，Popover 中的总量、已用、可用和百分比满足数值约束，
    并与操作系统对同一卷显示的容量在格式化和保留空间差异允许范围内一致

- AC-03
  - Given macOS 或 Linux 上选择一个有访问权限的本地目录
  - When 容量查询完成
  - Then 不调用 `df`，显示与 AC-02 相同的容量圆环和 Popover 字段

- AC-04
  - Given FTP 或 S3 端点配置成功
  - When 卡片完成渲染并保持至少一次容量刷新周期
  - Then 不调用后端容量查询，不显示容量 footer、圆环、加载占位或失败入口，卡片高度仍满足 AC-01

- AC-05
  - Given Local 容量查询仍在进行
  - When 查询超过 300ms
  - Then 右下角显示加载状态，路径和移除按钮不移动，卡片高度满足 AC-01

- AC-06
  - Given Local 容量查询返回错误或无效数值
  - When 用户点击警告入口并执行重试
  - Then Popover 说明容量暂不可用，重试显示加载状态，且端点配置、比较按钮和同步能力不受影响

- AC-07
  - Given Local 容量圆环可见
  - When 用户点击圆环、使用 Enter/Space 打开并使用 Escape 或外部点击关闭
  - Then Popover 正确开关，显示总量、已用、可用和百分比，焦点行为正确，且不会打开目录选择器或
    连接配置弹窗

- AC-08
  - Given 一个容量请求尚未返回
  - When 用户更换或移除端点，或者关闭同步会话
  - Then 旧请求结果被忽略，不写入新端点、不恢复已移除 UI，也不产生未处理异常

- AC-09
  - Given 旧版缓存会话包含 `storageCapacity`
  - When 应用恢复并再次保存该会话
  - Then 端点连接配置保留，旧容量不作为当前值显示，保存后的会话不再包含
    `storageCapacity`

- AC-10
  - Given 未选择端点并打开存储类型选择层
  - When 使用鼠标或键盘选择 Local、FTP、S3，或者通过关闭按钮/Escape 取消
  - Then 三个选项等宽、没有 Back 行、关闭语义正确，进入向上且退出向下，reduced motion 下动效
    被关闭或显著减弱，卡片高度始终满足 AC-01

- AC-11
  - Given 简体中文和英文，以及浅色、深色和跟随系统主题
  - When 查看所有容量和选择层状态
  - Then 文案完整，圆环、焦点、警告和 Popover 在两种语言与各主题下清晰可辨，长路径不会覆盖
    右侧操作区

- AC-12
  - Given 任意容量支持或失败状态
  - When 用户执行文件比较或同步
  - Then 容量功能不改变比较结果、传输方向、删除、覆盖、停止或错误恢复语义

- AC-13
  - Given 容量圆环和未选择端点卡片
  - When 分别查看卡片默认、hover 和键盘 focus 状态
  - Then 未使用轨道在默认背景上清晰可辨，hover 不出现包围圆环的大背景圈，focus 仍清晰；空状态
    只显示紧凑图形、端点角色和简短选择提示，卡片高度继续满足 AC-01

- AC-14
  - Given 已选择的 Local、FTP 或 S3 端点，并分别使用 `/`、短路径和长路径

- AC-15
  - Given 未选择和已选择端点卡片
  - When 分别使用常用宽度和最小窗口宽度查看
  - Then 未选择状态的角色与提示保持两行；已选择状态的类型、角色和路径共享左边界，路径使用统一

    上下居中

- AC-16

  - When 在浅色、深色和 hover 状态查看三个图标
  - Then 三者使用一致画布、单色细描边和圆角系统符号语言，不使用大面积填充，分别能辨识为本地

- 手工场景：
  - Windows Local：系统盘、非系统盘、长路径、查询失败、快速连续选择、移除和重试。
